# Primeiro prompt para o Antigravity

Abra a pasta clonada do repositório e envie:

> Este é um trabalho didático em dupla de Java e POO. Leia AGENTS.md, README.md e docs/REQUISITOS.md e docs/PLANO-DUPLA.md. Não implemente o jogo inteiro de uma vez. Primeiro verifique se existe código-base do professor e se o JDK está disponível. Se houver código-base, preserve suas assinaturas e hierarquia. Se ainda não houver, indique que a implementação será uma base nova seguindo o documento oficial. Proponha a primeira tarefa pequena: hierarquia de formas com seus construtores, validações, draw e intersects. Explique abstração, encapsulamento, herança e polimorfismo no código produzido. Use Java Swing/Graphics2D e Java Sound; não gere site. Após implementar a etapa, compile, informe os testes realmente realizados e apresente perguntas para nós dois verificarmos o entendimento. Aguarde nossa revisão antes de avançar para a próxima etapa. Mantenha o diagrama e os critérios de aceite atualizados.

## Trabalhando na dupla
Cada pessoa clona o mesmo repositório na própria máquina e usa sua branch. Antes de pedir alterações à IA, informar a tarefa e o responsável. Revisar o diff e executar antes de fazer commit. Não enviar senhas, tokens ou arquivos pessoais ao repositório.
